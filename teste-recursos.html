Verificação de Recursos

Como verificar se tudo está funcionando:
Siga os passos abaixo para testar os novos recursos.

📋 Passos para Testar:

  1. Clique no botão "Abrir Admin" abaixo
  2. Digite a senha: pcformatech2026
  3. Verifique se apareceram 6 abas no topo:
    • Dashboard
    • Clientes
    • Serviços
    • Orçamentos/Laudos ← NOVO
    • Produtos ← NOVO
    • Preços

Aba Produtos

O que você deve ver:

✓ Formulário para cadastrar produtos
✓ Campos: Nome, Preço, Estoque, Categoria, Descrição
✓ Botão "Cadastrar Produto"
✓ Tabela vazia (ou com produtos se já cadastrou)

Aba Orçamentos/Laudos

O que você deve ver:

✓ Botão "Novo Orçamento/Laudo"
✓ Barra de busca
✓ Tabela com colunas: Nº Laudo, Cliente, Data, Total, Tipo, Ações
✓ Tabela vazia (ou com orçamentos se já criou)

Abrir Admin e Testar
Se as abas não aparecerem:

1. Limpe o cache do navegador:
• Pressione Ctrl + Shift + Delete
• Selecione "Cache" ou "Arquivos em cache"
• Clique em "Limpar dados"
• Recarregue a página com Ctrl + F5

2. Abra em modo anônimo:
• Pressione Ctrl + Shift + N (Chrome)
• Ou Ctrl + Shift + P (Firefox)
• Abra o arquivo admin.html novamente

3. Verifique o Console:
• Pressione F12 para abrir as ferramentas de desenvolvimento
• Vá na aba "Console"
• Veja se há algum erro em vermelho
• Se houver, copie e me informe

🔍 Teste Rápido dos Recursos:

Teste 1: Cadastrar um Produto

1. Vá na aba "Produtos"
2. Preencha: Nome = "Teste SSD", Preço = 100
3. Clique em "Cadastrar Produto"
4. Deve aparecer na tabela abaixo

Teste 2: Criar um Orçamento

1. Vá na aba "Orçamentos/Laudos"
2. Clique em "Novo Orçamento/Laudo"
3. Selecione um cliente (cadastre um antes se necessário)
4. Clique em "Adicionar Serviço" e selecione um
5. Clique em "Salvar Orçamento/Laudo"
6. Deve aparecer na tabela

Teste 3: Gerar PDF

1. Na tabela de orçamentos, clique no botão "PDF"
2. Um arquivo PDF deve ser baixado automaticamente
3. Abra e verifique se está formatado corretamente
