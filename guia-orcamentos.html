✓ Comprovante de trabalho

Como Cadastrar Produtos

  1. Acesse a aba "Produtos" no painel admin
  2. Preencha o nome do produto (ex: "SSD Knup 128GB")
  3. Informe o preço (ex: R$ 207,87)
  4. Defina a quantidade em estoque (ex: 5 unidades)
  5. Escolha a categoria (Hardware, Software, Periféricos, etc.)
  6. Adicione uma descrição se desejar
  7. Clique em "Cadastrar Produto"

Exemplo de Produto:

Nome: SSD Knup 128GB
Preço: R$ 207,87
Estoque: 5 unidades
Categoria: Hardware
Descrição: SSD SATA III 2.5" de alta performance

Como Criar Orçamento/Laudo

  1. Acesse a aba "Orçamentos/Laudos"
  2. Clique em "Novo Orçamento/Laudo"
  3. Selecione o Cliente da lista
  4. Escolha a Data
  5. Defina o Tipo (Orçamento ou Laudo)
  6. Clique em "Adicionar Serviço" e selecione da lista
  7. Clique em "Adicionar Produto" e selecione da lista
  8. Para laudos, preencha: Defeito, Laudo Técnico, Solução, Observações e Garantia
  9. Clique em "Salvar Orçamento/Laudo"
  10. Clique em "Gerar PDF" para baixar

Dicas Importantes

Preços Automáticos
Ao selecionar um serviço ou produto, o preço é preenchido automaticamente. Mas você pode alterá-lo manualmente se precisar fazer desconto ou ajuste.
Estoque Manual
O sistema NÃO atualiza o estoque automaticamente ao usar produtos em orçamentos/laudos. Você deve atualizar manualmente na aba "Produtos".
Numeração Sequencial
Os laudos são numerados automaticamente (0001-25, 0002-25, etc.). Não é possível alterar o número manualmente para evitar duplicidades.

Fluxo de Trabalho Recomendado

📊 Criar Orçamento:

  1. Cliente solicita orçamento via WhatsApp
  2. Cadastre o cliente (se não existir)
  3. Crie novo orçamento no sistema
  4. Adicione serviços e produtos necessários
  5. Gere o PDF
  6. Envie pelo WhatsApp ao cliente
  7. Aguarde aprovação

📋 Criar Laudo Técnico:

  1. Execute o serviço no computador do cliente
  2. Crie novo laudo técnico no sistema
  3. Adicione serviços realizados
  4. Adicione produtos utilizados/vendidos
  5. Preencha: Defeito, Laudo, Solução, Observações e Garantia
  6. Gere o PDF
  7. Entregue o PDF ao cliente junto com o computador
  8. Atualize o estoque dos produtos utilizados

Como Enviar PDF pelo WhatsApp

  1. Gere o PDF (será baixado automaticamente)
  2. Na lista de clientes, clique no botão "WhatsApp"
  3. No WhatsApp, clique no ícone de "Anexar" (📎)
  4. Selecione "Documento"
  5. Escolha o PDF que você gerou
  6. Adicione uma mensagem explicativa
  7. Envie!
